API： GET 域名 + /api/v1/referral/bonus/list

## Header 参数

| **名称** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| Authorization | string | 必填 | 鉴权access_token |
| Platform | string | 必填 | 固定为:open_platform |

## QueryString 参数

| **名称** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| limit | number | 必填 | 每页数量（分页数量1-100） |
| timeStart | string | 必填 | 开始时间（2025-01-07 10:00:00） |
| timeEnd | string | 必填 | 结束时间（2025-01-07 10:38:14） |
| lastId | number | 选填 | 最后一个记录id，分页传入 |
| uid | number | 选填 | 分享人用户uid |
| bonusStatus | number | 选填 | 结算状态[-1：全部，0：待结算 1：已结算 2：已退款] |

## 返回数据

| **名称** |  | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- | --- |
| lastId |  | number | 必填 | -1代表最后一页（无需再翻页查询）<br>其他代表下一页开始的文件id，携带到请求参数中 |
| list |  | array | 必填 | 佣金列表 |
|  | id | number | 必填 | 记录id |
|  | uid | number | 必填 | 分享人uid |
|  | mobile | sring | 必填 | 被分享人手机号码 |
|  | sourceType | number | 必填 | 佣金来源类型[1：会员 2：付费免登录下载 3：转存] |
|  | paid | number | 必填 | 付费金额（单位：分） |
|  | bonus | number | 必填 | 分佣金额（单位：分） |
|  | productName | string | 必填 | 产品名称 |
|  | createTime | string | 必填 | 佣金记录生成时间 |
