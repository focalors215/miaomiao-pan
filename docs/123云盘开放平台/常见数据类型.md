### 一、基础数据类型

| **类型名称** | **说明** | **示例** |
| --- | --- | --- |
| **string** | 字符串类型，用于表示文本信息。 | `"name": "张三"` |
| **integer** | 整数类型，不带小数部分的数字。 | `"age": 25` |
| **number** | 数字类型，可包含整数或浮点数。 | `"price": 19.99` |
| **boolean** | 布尔类型，仅允许 `true`<br>或 `false`<br>。 | `"is_valid": true` |
| **null** | 空值，表示字段值为空。 | `"data": null` |

### 二、复杂数据类型

| **类型名称** | **说明** | **示例** |
| --- | --- | --- |
| **array** | 数组类型，由相同或不同类型的元素组成。需明确元素类型。 | `"ids": [1, 2, 3]`<br>（整型数组）<br>`"tags": ["A", "B"]`<br>（字符串数组） |
| **object** | 对象类型，由键值对组成的结构化数据。需定义内部字段及类型。 | `"user": { "name": "李四", "age": 30 }` |
| **nested** | 嵌套类型，对象或数组内部包含其他复杂类型。 | `"data": { "items": [{"id": 1}, {"id": 2}] }` |

### 三、特殊格式类型

| **类型名称** | **说明** | **格式要求及示例** |
| --- | --- | --- |
| **date** | 日期类型，通常遵循 `YYYY-MM-DD`<br>格式。 | `"birthday": "1990-05-15"` |
| **datetime** | 日期时间类型，通常遵循 ISO 8601 标准（`YYYY-MM-DDTHH:mm:ssZ`<br>）。 | `"created_at": "2023-10-01T14:30:00+08:00"` |
| **enum** | 枚举类型，字段值必须为预定义列表中的某一项。 | `"status": "active"`<br>（允许值：`active`<br>、`inactive`<br>、`pending`<br>） |
| **file** | 文件类型，用于上传文件（需配合 `multipart/form-data`<br>格式使用）。 | `"avatar": <file>`<br>（通过表单上传） |
| **binary** | 二进制数据，常用于传输图片、音频等非文本内容。 | `"image": "base64编码字符串"` |
