## 接口定义

API： `请求method` `域名 + 接口path`

说明：此处维护接口特殊说明

## Header 参数

| **名称** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| Content-Type | string | 必填 | application/json |
| [其他Header参数] | [类型] | [是否必填] | [说明] |

## Body 参数（POST/PUT请求）

| **名称** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| id | array | 必填 | 文件id数组 |
| [...] | [...] | [...] | [...] |

## QueryString参数（GET/DELETE请求）

| **名称** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| fileIDs | array | 必填 | 文件id数组 |
| [...] | [...] | [...] | [...] |

## 返回数据(Data)

-   **普通返回**

| **名称** | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- |
| fileID | number | 必填 | 文件ID |
| filename | string | 必填 | 文件名 |
| type | number | 必填 | 0-文件 1-文件夹 |
| [...] | [...] | [...] | [...] |

-   **数组返回**

| **名称** |  | **类型** | **是否必填** | **说明** |
| --- | --- | --- | --- | --- |
| fileList |  | array | 是 | ​ |
| ​ | fileList[*].fileId | number | 是 | 文件ID |
| ​ | fileList[*].filename | string | 是 | 文件名 |
| ​ | fileList[*].parentFileId | number | 是 | 目录ID |
| ​ | [...] | [...] | [...] | [...] |

    "etag": "4b5c549c4abd0a079caf92d6cad24127",

    'Platform': 'open_platform',
    'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJl...(过长省略)'
